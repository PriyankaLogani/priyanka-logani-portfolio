# 🌐 Priyanka Logani — Portfolio Website

This is my personal portfolio website showcasing my work as a **Software Engineer**, specializing in **Java**, **Spring Boot**, **Backend Engineering**, **Distributed Systems**, **Microservices**, **Security (SAST/DAST)**, and **Full-Stack Development**.  
The portfolio is built with modern web technologies and hosted online for recruiters, hiring managers, and anyone interested in my work.

## ✨ Features

- 🎨 **Futuristic dark-mode UI** with smooth gradients  
- ⚡ **Vite + React** fast-loading frontend  
- 🎬 **Animations on scroll** (fade, slide, smooth transitions)  
- 🚀 **Highly responsive** design (mobile, tablet, desktop)  
- 🧩 **Modular component architecture** with shadcn UI  
- 📄 **Resume section** with download button  
- 🧠 **Projects section** with curated software engineering projects  
- 📝 **Blog section** for long-form writing  
- 📚 **Notes section** (digital garden) for quick tech notes  
- 🌐 **SEO tags + metadata** for rich previews  
- 🛡 **Secure coding principles** in project content
